# Pusepuh - Platform Komunitas Seniman Visual Indonesia 🎨

Pusepuh adalah aplikasi mobile komunitas berbasis *board* dan *thread* yang didesain khusus untuk mewadahi interaksi seniman lokal secara sehat. Aplikasi ini memfasilitasi kreator (terutama pemula) untuk mendapatkan kritik teknis yang membangun, membagikan karya *Work in Progress* (WIP), serta menemukan lokasi acara seni dengan mudah.

Proyek ini dikembangkan untuk memenuhi Tugas Akhir mata kuliah Pemrograman Perangkat Bergerak.

## Daftar Fitur
Aplikasi ini telah memenuhi spesifikasi fungsionalitas utama yang mencakup:
1. **Multi-page Navigation**: Sistem navigasi dan *routing* yang mulus antar halaman (Home, Board, Thread, Profile).
2. **Database & API Integration**: Penyimpanan data pengguna dan *thread* menggunakan *server-based database*.
3. **Integrasi Kamera**: Dukungan pengambilan gambar karya atau sketsa langsung melalui kamera perangkat.
4. **Local File Storage**: Fitur untuk menyimpan gambar referensi ke galeri HP dan mengunggah gambar dari penyimpanan lokal.
5. **Peta Lokasi (Google Maps)**: Penyematan lokasi acara komunitas (*meetup*, pameran) di dalam *board* Info menggunakan marker interaktif.
6. **Push Notification**: Pemberitahuan *real-time* saat terjadi interaksi antar pengguna di dalam *thread*.
7. **Sistem Tagging Kritik**: Fitur wajib bagi kreator untuk memilih level kritik (misal: *Soft Critique, Hard Roast*) guna menjaga ekosistem yang sehat.
8. **State Management & Error Handling**: Implementasi *Clean Architecture* untuk mengelola *state* dan penanganan *error* (seperti koneksi terputus atau data kosong) secara aman.
